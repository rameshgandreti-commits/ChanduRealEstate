2 — Deploy to Railway (Step by Step)

1
Push your project to GitHub Create a free account at github.com, create a new repo (e.g. chandu-real-estate), and push your code:
git init git add . git commit -m "Initial commit" git remote add origin https://github.com/YOUR_USERNAME/chandu-real-estate.git git push -u origin main
2
Sign up at Railway Go to railway.app → click Start a New Project → choose Deploy from GitHub repo → select your repo.
3
Set the PORT environment variable In Railway dashboard → your service → Variables tab → add:
PORT = ${{PORT}}
Railway injects PORT automatically; your server.js already reads it via properties['port'] || 3000. Add one more variable:
WHATSAPP_NUMBER = +919886126344
4
Verify the start command Railway will auto-detect "start": "node server.js" from your package.json. No extra config needed.
5
Get your free URL After deploy, go to Settings → Networking → Generate Domain. You get a free URL like chandu-real-estate.up.railway.app with HTTPS automatically.

3 — Free Domain Options (Pick One)

Option A — Freenom (.tk / .ml / .ga / .cf / .gq) Free

Register chandurealestate.tk or chandurealestate.ml for free at freenom.com. Free for 12 months, renewable. Then point CNAME to your Railway domain.

⚠ Freenom free domains are sometimes unavailable for new registrations. If the site doesn't work, use Option B or C.

Option B — js.org subdomain (*.js.org) Free & reliable

Get a free subdomain like chandurealestate.js.org via a GitHub Pull Request to the js-org/js.org repo. Permanent and free.

  • Fork the repo → add one line to cnames_active.js: "chandurealestate": "chandu-real-estate.up.railway.app"
  • Submit a Pull Request → approved in 1–3 days.

Option C — is-a.dev subdomain (*.is-a.dev) Free & developer-friendly

Register chandurealestate.is-a.dev free via a PR to is-a-dev/register. Add a JSON file and submit a PR.

Option D — Cheapest paid option (.in domain) ~₹699/year

For a real .com or .in domain, use BigRock or GoDaddy. A .in domain costs ~₹699/year — very affordable for a business site.

4 — Connect Your Free Domain to Railway

1
In Railway — go to your service → Settings → Networking → Custom Domain → enter your domain (e.g. chandurealestate.tk).
2
In your domain registrar DNS settings — add a CNAME record:
Type: CNAME Name: www (or @) Value: chandu-real-estate.up.railway.app
3
Wait 5–30 minutes for DNS propagation. Railway auto-issues an SSL/HTTPS certificate (via Let's Encrypt). Your site will be live at https://chandurealestate.tk.

5 — Update robots.txt & sitemap.xml

Once your domain is confirmed, update two files in your project to reflect the real URL:

public/robots.txt — change the Sitemap URL to your new domain.

public/sitemap.xml — replace all occurrences of https://www.chandurealestate.com with your actual domain (e.g. https://chandurealestate.tk).

Commit and push — Railway redeploys automatically.
