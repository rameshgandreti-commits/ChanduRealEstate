GitHub Pages Repository Settings

After adding DNS records at your registrar, configure these settings in the GitHub repository:

1
Open repository Settings → Pages Go to github.com / <your-username> / <repo> / settings / pages
2
Source — set to GitHub Actions The pages.yml workflow already handles deployment from the public/ folder.
3
Custom domain — enter your domain Type www.ChanduRealEstate.com and click Save. GitHub will verify DNS and issue a free TLS certificate.
4
Enforce HTTPS — enable the checkbox Appears automatically once DNS verification passes (usually 5–30 minutes after DNS propagates).
The public/CNAME file already contains www.ChanduRealEstate.com, so each deployment automatically keeps GitHub Pages configured correctly.

Google Search Console Verification (TXT Record)

Google Search Console requires a TXT record to verify domain ownership. Add it once you have the token from Google.

TypeHost / NameValueTTL
TXT @ google-site-verification=<your-token-here> 3600

Get the token from search.google.com/search-console → Add Property → DNS verification method.

Verify DNS Propagation

After saving records, use these tools to confirm propagation (takes 15 min – 48 hours):

Global checker
whatsmydns.net
DNS lookup
dnschecker.org
PowerShell (local)
Resolve-DnsName www.ChanduRealEstate.com
Expected CNAME answer
ramesh-somani.github.io
All good when: A records resolve to all four 185.199.10x.153 IPs, the CNAME for www points to *.github.io, and https://www.ChanduRealEstate.com loads with a valid TLS certificate.
